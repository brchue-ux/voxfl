# voxfl

AI-assisted EDM/music composition.

## Status

Concept-design phase.

No stack, platform, FL Studio integration approach, or audio/pitch-interpretation
method has been chosen. Nothing here is locked.

Two interaction modes are under consideration, neither settled:

- **Voice mode** — mic input (humming, beatboxing, singing) through an interpretation
  layer into an editable FL Studio track, with on-the-fly correction of pitch, key,
  and plugin parameters.
- **Piano mode** — real-time piano input, where the AI suggests candidate key
  sequences played live, iterating on timing and note density/length.

The central open technical question is how software actually gets musical content
into FL Studio. It is unresolved, and little else can be honestly designed until
it is.
